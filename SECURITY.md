# Security Policy

## Supported Versions

`<h1code>` is in early development. Only the current minor line receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please report security issues through GitHub’s **private vulnerability reporting** on this repository:

[Report a vulnerability](https://github.com/parasite6/-h1code-/security/advisories/new)

Do **not** open a public issue for security-sensitive reports.

### What to expect

- We will acknowledge valid reports as soon as practical (typically within a few days).
- If the report is accepted, we will work on a fix and coordinate disclosure through the advisory.
- If the report is declined, we will explain why (e.g. not reproducible, out of scope, or already fixed).
- Please include enough detail to reproduce the issue (affected version/commit, environment, steps, and impact).
